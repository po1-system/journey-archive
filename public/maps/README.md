# Japan geographical base

`japan-context.geojson`: Japan, Taiwan, South Korea and North Korea extracted without coordinate changes from Natural Earth 1:50m Admin 0 Countries (public domain).

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Natural Earth terms: https://www.naturalearthdata.com/about/terms-of-use/

Coordinates are WGS84 longitude/latitude. The renderer applies the same Mercator projection to both coastlines and journey anchors. Okinawa is not an inset. This is a generalized geographic map, not survey data or measured terrain. Vertical extrusion is a visual relief, not altitude data. The journey lines connect trips chronologically, not actual flights or rail tracks.
